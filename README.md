# pugmk

`pugmk` — мини-язык программирования на русском языке с расширением `.pugs`.

## Возможности

- переменные: `пусть x = 10`
- условия: `если ... { ... } иначе { ... }`
- циклы: `пока ... { ... }`
- функции: `функция имя(парам) { ... вернуть ... }`
- встроенные функции:
  - `печать(...)`
  - `ввод(подсказка)`
  - `длина(строка_или_список)`
  - `сохранить_файл(путь, текст)`

## Запуск

```bash
python3 pugmk.py examples/hello.pugs
```

## Пример

```pugs
функция факториал(n) {
    если n <= 1 {
        вернуть 1
    }
    вернуть n * факториал(n - 1)
}

пусть число = 6
печать("факториал:", факториал(число))
```

## Папка `примеры`

- `примеры/плеер.html` — готовый рабочий плеер с дизайном из макета.
- `примеры/плеер.pugs` — тот же плеер, но создаётся **на языке pugmk** (генерирует HTML-файл).

Сгенерировать HTML из `pugmk`:

```bash
python3 pugmk.py примеры/плеер.pugs
```
